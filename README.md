# Find In Files

<img src="./logo-mascot.png" alt="Find In Files 吉祥物图标" width="120">

一个 uTools 文件内容搜索插件。选择本地目录，输入关键词，即可查找代码、日志和文本文件中的匹配行，并在页面中查看或导出结果。

## 功能

- 搜索目录及其子目录中的 UTF-8 文本，按文件分组展示匹配内容和行号。
- 筛选文件类型，也可以排除指定文件名或 `.log` 文件；多个条件同时生效。
- 查看搜索进度、取消任务；新搜索失败或取消时保留上一轮结果。
- 打开原文件或所在位置、复制路径和匹配行；长行可以展开查看。
- 自动将结果保存为 Markdown，保存失败时可直接重试。
- 支持浅色和深色主题、键盘操作，以及返回页面顶部。

## 安装与启动

在 uTools 插件商店搜索 `FindAnyThingInFile`，或在 uTools 开发者工具中新建插件并选择本项目目录。

启动时可输入 `find`、`find in files`、`文件内容搜索`、`搜索文件内容`、`搜索文件` 或 `文件内容匹配`。`搜索Java文件` 也可作为兼容旧版的启动关键词；实际文件范围由插件内设置决定。

## 使用方法

1. 在首页点击搜索框下方的目录入口，选择要搜索的文件夹。首次搜索时如果还未选择目录，页面会提示配置。
2. 输入关键词，按 Enter 或点击搜索框右侧的箭头。搜索按原文匹配，区分大小写，不支持正则表达式或跨行匹配。
3. 如需缩小范围，点击文件类型入口，选择全部文本文件或指定文件类型。也可填写自定义后缀，例如 `.vue, .go, .properties`。
4. 在文件范围旁点击排除文件，可选择常见文件、AI 开发配置文件或填写自定义文件名。自定义项每行一个完整文件名，区分大小写，对所有子目录生效；`.log 文件` 按后缀排除，不区分大小写。
5. 在结果区查看匹配。页面首次显示 100 行，点击再显示可继续加载；向下滚动后可使用返回顶部按钮。

插件会记住搜索目录、文件类型和排除设置。常见排除选项默认不勾选；文件必须符合所选类型且不在排除范围内，才会被搜索。

## 搜索结果与导出

结果按文件分组，展示文件名、相对目录、匹配行号和内容。点击文件名可用系统默认应用打开原文件；每个文件还提供打开位置和复制路径操作。

每次搜索完成后，插件会在下载目录生成 Markdown 文件。表格包含项目名、文件名、文件类型、行号和内容；没有匹配时也会生成说明文件。若保存失败，页面会保留搜索结果并提供重新保存操作。

搜索和导出在本地完成。导出文件名包含搜索内容，文件内包含匹配行，分享前请检查是否有敏感信息。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Enter | 在搜索框中开始搜索，或执行当前聚焦的按钮操作 |
| Esc | 取消进行中的搜索，保存阶段除外 |
| ⌘ K / Ctrl K | 聚焦搜索框 |
| Tab | 浏览页面操作 |

## 搜索范围与限制

- 搜索前会去掉关键词首尾空白；匹配行展示和导出时也会去掉行首尾空白。
- 目前仅按 UTF-8 读取文件，自动跳过符号链接，不跟随链接进入其他目录。
- 常见二进制后缀会自动排除，包括图片、音视频、压缩包、办公文件和 `.whl` 包。按后缀判断无法识别所有二进制文件。
- 无法读取的文件或子目录会跳过，并在结果摘要中提示；搜索根目录无法读取时会显示错误。
- 文件按行读取，但匹配结果会保存在内存中，匹配内容较多时可能占用较多内存。

## 开发与测试

项目使用原生 HTML、CSS 和 JavaScript，文件系统操作位于 `preload.js`，页面交互位于 `index.js`。无需安装依赖或构建，使用 Node.js 18 及以上执行：

```sh
node --check index.js
node --check preload.js
node --test tests/*.test.js
git diff --check
```

测试使用临时目录、模拟的 uTools API 和轻量 DOM。实际目录选择、剪贴板和系统文件打开行为仍需在 uTools 中验证。

```text
.
├── index.html          # 页面结构
├── index.css           # 页面样式
├── index.js            # 页面交互
├── preload.js          # 搜索、导出和系统操作
├── plugin.json         # uTools 插件配置
├── logo-mascot.png     # 插件图标
├── logo-mascot.svg     # 图标矢量源文件
├── docs/               # 图标说明和界面图片
└── tests/              # Node.js 回归测试
```

图标源文件及导出说明见 [图标说明](./docs/logo-generation.md)。
