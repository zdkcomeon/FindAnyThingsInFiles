# Logo 生成说明

新版插件图标为根目录下的 `logo-v2.png`，尺寸为 256×256 像素，PNG 格式，圆角底板外透明。

图标使用内置 `image_gen` 工具生成，再通过 macOS `sips` 等比例缩小。暖橙色沿用界面的 `#b94c2f`，文件、内容行和放大镜表示文件内容搜索。

`plugin.json` 的 `logo` 字段已指向新版图标，原有 `logo.png` 保留供参考。

## 完整生成提示词

```text
为 Find In Files 本地文件内容搜索插件设计一个专业应用 logo：以圆角暖橙色（#b94c2f）底板、米白色折角文件和右下角放大镜组成简洁的扁平图形。放大镜聚焦一条内容行，粗线条、轮廓清晰，适合缩小到 256×256 像素。方形画布，四周留出均匀边距，底板外透明。只生成一个图标，无文字、无水印、无展示样机。
```
